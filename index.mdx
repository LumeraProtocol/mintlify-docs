Lumera Protocol is a Layer 1 blockchain built on the Cosmos SDK. It makes permanent file storage and AI powered content services native features of the chain. The LUME token pays for staking, transaction fees, and storage.

The chain also ships CosmWasm smart contracts, IBC connections to the wider Cosmos ecosystem, and EVM support.

## Cascade

Cascade is Lumera's permanent storage service with a pay once, store forever model. Your file is encoded with RaptorQ erasure coding and spread across the network, and any large enough subset of the pieces can rebuild it.

## Sense

Sense is Lumera's AI powered content authentication service. It detects near-duplicate media and manipulated content across the network.

## How the network runs

Validators secure the chain through delegated proof of stake. Validators can also run a SuperNode, a companion daemon that provides Cascade and Sense services and earns proof of service rewards. The `v1.20.0` release added EVM support, live on testnet today, so Solidity contracts deploy with standard [EVM tooling](/smart-contracts/overview).

Lumera is the evolution of Pastel Network, rebuilt as a Cosmos chain.
