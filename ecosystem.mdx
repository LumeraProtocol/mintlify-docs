## Developer tools

| Tool | Description |
|---|---|
| [`@lumera-protocol/sdk-js`](https://www.npmjs.com/package/@lumera-protocol/sdk-js) | TypeScript SDK for Node.js and browsers, published on npm. |
| [`sdk-go`](https://github.com/LumeraProtocol/sdk-go) | Go SDK covering gRPC queries, transactions, and Cascade uploads and downloads. |
| [`lumerad`](https://github.com/LumeraProtocol/lumera) | Full node and wallet CLI that ships with the chain. |
| [`rq-go`](https://github.com/LumeraProtocol/rq-go) | Official Go library for RaptorQ (RFC 6330) erasure coding. |
| [LumeScope](https://github.com/LumeraProtocol/lumescope) | Read-only REST API aggregator serving decoded action metadata, Cascade previews, and SuperNode metrics. |

Start with the [JavaScript SDK](/sdk/javascript) or [Go SDK](/sdk/go) docs. LumeScope endpoints are covered in the [API reference](/api/overview).

## Infrastructure

| Repository | Description |
|---|---|
| [`supernode`](https://github.com/LumeraProtocol/supernode) | Companion daemon that validators run to provide Cascade and Sense services. |
| [`lumera-networks`](https://github.com/LumeraProtocol/lumera-networks) | Genesis files, seeds, network configs, and operator manuals. |

## Wallets

| Wallet | Description |
|---|---|
| Keplr | Cosmos wallet that uses bech32 `lumera1...` addresses. |
| Leap | Cosmos wallet supported by the JavaScript SDK. |
| MetaMask | Ethereum wallet that uses hex `0x...` addresses once an account completes [EVM migration](/upgrades/evm-upgrade). |

See the [Hub wallet guide](/hub/wallet) for setup.
